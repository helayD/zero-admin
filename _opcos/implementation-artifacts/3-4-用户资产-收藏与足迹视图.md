# Story 3.4: 用户资产、收藏与足迹视图

## Status: done

## Story

As a 消费者,
I want 查看积分、成长值、优惠券、收藏、足迹和关注内容,
So that 我可以了解自己的权益与后续消费线索。

## FRs Implemented

- **FR11**: 消费者可以查看个人资产与统计信息，包括积分、成长值、优惠券和订单概览。
- **FR12**: 消费者可以查看自己的收藏、足迹、关注和相关会员内容。

## Epic Context

- **Epic 3**: 会员账户、地址与用户资产中心
- **前置 Story 依赖**: Story 3.1（登录）✅ done, Story 3.2（个人资料）✅ done, Story 3.3（收货地址）✅ done

## Acceptance Criteria

### AC1: 个人资产页展示积分、成长值、优惠券和订单摘要

**Given** 消费者已登录
**When** 打开个人资产页（我的页面）
**Then** 系统展示积分、成长值、优惠券和订单摘要
**And** 同时提供收藏、足迹、关注等会员相关内容入口

**验证要点：**
- mine.dart 的 `buildIntegral()` 已显示积分、成长值、优惠券数量 ← 已有，需验证正确性
- mine.dart 的 `buildOrderInfo()` 已显示订单入口 ← 已有
- mine.dart 的 `buildSetting()` 已有足迹、关注、收藏导航入口 ← 已有

### AC2: 收藏列表展示与管理

**Given** 消费者进入"我的收藏"页面
**When** 页面加载
**Then** 展示收藏的商品列表，包含商品图片、名称、副标题、价格
**And** 支持取消收藏（单条删除）
**And** 支持清空全部收藏
**And** 点击商品跳转到商品详情
**And** 加载中显示 loading 状态
**And** 请求失败显示错误提示与重试按钮
**And** 无收藏时显示空状态与推荐操作

### AC3: 足迹列表展示与管理

**Given** 消费者进入"我的足迹"页面
**When** 页面加载
**Then** 展示浏览过的商品列表，包含商品图片、名称、副标题、价格、浏览时间
**And** 支持删除单条足迹记录
**And** 支持清空全部足迹
**And** 点击商品跳转到商品详情
**And** 加载中显示 loading 状态
**And** 请求失败显示错误提示与重试按钮
**And** 无足迹时显示空状态与推荐操作

### AC4: 关注列表展示与管理

**Given** 消费者进入"我的关注"页面
**When** 页面加载
**Then** 展示关注的品牌列表，包含品牌 logo、品牌名称
**And** 支持取消关注（单条删除）
**And** 支持清空全部关注
**And** 点击品牌跳转到品牌详情
**And** 加载中显示 loading 状态
**And** 请求失败显示错误提示与重试按钮
**And** 无关注时显示空状态与推荐操作

### AC5: 空状态处理

**Given** 某项资产或会员内容暂无数据
**When** 消费者进入对应视图
**Then** 页面提供清晰空状态和下一步推荐操作
**And** 不显示与当前主体无关的其他租户或商户数据

### AC6: 未登录态保护

**Given** 消费者未登录
**When** 尝试访问收藏、足迹、关注等需要鉴权的页面
**Then** 401 拦截跳转登录页
**And** 登录后可回到原页面（降级为 pop 回原页面 + 重试，受限于项目架构无命名路由）

## Dev Notes

### 架构约束

- Flutter 网络请求统一使用 `HttpUtil`（Dio 封装），禁止私建网络栈
- URL 常量统一定义在 `service_url.dart`
- 所有异步回调中 `setState` 前必须添加 `mounted` 检查
- 401 拦截由 `http_util.dart` 全局 interceptor 处理，push Login → pop 回原页面

### 已有后端 API（front-api routes.go 已注册，JWT 保护）

| 功能 | HTTP Method | 路径 | 说明 |
|------|-------------|------|------|
| 收藏列表 | GET | `/api/member/queryCollectionList` | 查询收藏商品列表 |
| 添加收藏 | POST | `/api/member/addtCollection` | 注意路径有 typo: "addtCollection" |
| 删除收藏 | GET | `/api/member/deleteCollection` | 参数: ids |
| 清空收藏 | GET | `/api/member/clearCollection` | 清空当前用户所有收藏 |
| 足迹列表 | GET | `/api/member/queryReadHistoryList` | 查询浏览历史 |
| 添加足迹 | POST | `/api/member/addReadHistory` | 浏览商品时自动调用 |
| 删除足迹 | GET | `/api/member/deleteReadHistory` | 参数: ids |
| 清空足迹 | GET | `/api/member/clearReadHistory` | 清空当前用户所有足迹 |
| 关注列表 | GET | `/api/member/queryAttentionList` | 查询关注品牌列表 |
| 添加关注 | POST | `/api/member/addAttention` | 关注品牌 |
| 删除关注 | GET | `/api/member/deleteAttention` | 参数: ids |
| 清空关注 | GET | `/api/member/clearAttention` | 清空当前用户所有关注 |

### 关键风险

1. **delete/clear 接口参数格式（已确认）**:
   - 收藏删除: `GET /deleteCollection?ids=xxx` — `CollectionDeleteReq { Ids []string \`form:"ids"\` }`
   - 足迹删除: `GET /deleteReadHistory?ids=xxx` — `ReadHistoryDeleteReq { Ids []string \`form:"ids"\` }`
   - ⚠️ 关注删除: `GET /deleteAttention?brandIds=xxx` — `DeleteAttentionReq { BrandIds []int64 \`form:"brandIds"\` }`（参数名和类型不同！）
   - 三个 clear 接口均无参数
2. **模型文件名 typo**: `hisotry_list.dart` 文件名有拼写错误，本 Story 不修改以避免破坏现有 import 引用
3. **后端 addtCollection 路径 typo**: 路径为 `/addtCollection` 而非 `/addCollection`，仅在添加收藏时需注意，本 Story 以列表展示和删除为主

### Previous Story Intelligence (Story 3.3)

- **Error handling 模式**: try-catch + `_isLoading`/`_errorMessage` 状态字段 + 三态 UI（loading / error / content）
- **删除确认**: `showDialog<bool>` + AlertDialog + 确认/取消按钮
- **空状态**: Center + Column + Icon + Text + ElevatedButton
- **mounted 检查**: 每个异步回调 setState 前必须检查 `if (!mounted) return`
- **列表刷新**: 操作成功后调用查询方法重新加载列表
