# Story 6.1: 订单列表与详情时间线

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a 消费者,
I want 按状态查看订单列表并打开订单详情,
So that 我可以随时知道每笔订单当前进行到了哪一步。

## Acceptance Criteria

1. **Given** 消费者已有历史订单 **When** 打开订单列表并按状态筛选 **Then** 系统展示对应订单摘要、金额、商户和当前状态 **And** 不同状态下的订单可以进入统一详情页。

2. **Given** 消费者进入订单详情页 **When** 页面加载完成 **Then** 系统通过 `Order Timeline Panel` 展示创建、支付、发货、售后等关键节点 **And** 同步展示商品明细、金额拆分和收货信息。

### 正确通信拓扑

```
订单列表：
flutter-mall → front-api（GET /api/order/list?status=0&pageNum=1&pageSize=10）
  → OrderListLogic: 校验 memberId（从 JWT）→ OMS QueryOrderList（memberId + status + pagination）
  → 返回订单摘要列表（orderSn/status/payStatus/totalAmount/merchantName/createdAt/thumbnail）

订单详情：
flutter-mall → front-api（GET /api/order/detail/:orderId）
  → OrderDetailLogic: 校验 memberId + orderId 归属 → OMS QueryOrderDetail
  → 构建时间线数组 + 金额拆分 + 收货信息
  → 返回完整 OrderDetailResp
```
