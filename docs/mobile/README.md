# 移动端文档

## 概述

Flutter Mall 是基于 Flutter 的电商移动端应用。

## 技术栈

- Flutter
- Dart

## 主要功能

### 用户模块
- 会员登录/注册
- 个人信息
- 收货地址管理
- 密码修改

### 商品模块
- 商品列表
- 商品详情
- 商品搜索
- 品牌列表
- 分类列表

### 订单模块
- 购物车
- 订单生成
- 订单列表
- 订单详情
- 取消订单
- 退货申请

### 会员模块
- 收藏管理
- 足迹管理
- 关注品牌

### 优惠券
- 优惠券列表
- 领取优惠券

## 目录结构

```
flutter-mall/
├── lib/
│   ├── main.dart
│   ├── pages/          # 页面
│   ├── widgets/        # 组件
│   ├── services/       # 服务
│   ├── models/         # 模型
│   └── utils/          # 工具
└── pubspec.yaml
```
