## 目录结构

```
zero-admin/
├── api/                    # API 网关
│   ├── admin/             # 管理端 API
│   └── front/             # 用户端 API
├── rpc/                   # RPC 微服务
│   ├── sys/              # 系统管理
│   ├── ums/              # 会员管理
│   ├── pms/              # 商品管理
│   ├── oms/              # 订单管理
│   ├── sms/              # 营销管理
│   ├── cms/              # 内容管理
│   └── search/           # 搜索服务
├── web-admin/             # React 管理前端
├── flutter-mall/          # Flutter 移动端
├── consumer/              # 消息消费者
├── job/                   # 定时任务
├── pkg/                   # 公共包
├── script/                # 脚本
├── docs/                  # 项目文档
└── gogogo/               # BMAD 工作区
```

## 核心模块说明

### 1. 系统管理 (sys)
- 用户管理
- 角色管理
- 菜单管理
- 部门管理
- 字典管理
- 日志管理

### 2. 会员管理 (ums)
- 会员注册/登录
- 会员等级
- 收货地址
- 积分管理
- 成长值
- 收藏/关注

### 3. 商品管理 (pms)
- 商品分类
- 商品品牌
- 商品属性
- SKU/SPU 管理
- 商品评价

### 4. 订单管理 (oms)
- 订单创建/查询
- 订单发货
- 订单退货/退款
- 购物车

### 5. 营销管理 (sms)
- 优惠券
- 秒杀活动
- 首页广告

### 6. 内容管理 (cms)
- 专题管理
- 优选专区
- 话题管理
