# 后端服务文档

## 概述

Zero-Admin 后端采用 go-zero 框架构建的微服务架构。

## API 网关

### admin-api (管理端)
- 端口: 8000
- 路径: `api/admin/`

### front-api (用户端)
- 端口: 9999
- 路径: `api/front/`

## RPC 服务

### sys (系统管理)
- 端口: 8001
- 功能: 用户、角色、菜单、部门、字典、日志

### ums (会员管理)
- 端口: 8002
- 功能: 会员、地址、积分、成长值、收藏

### pms (商品管理)
- 端口: 8003
- 功能: 商品、分类、品牌、属性、SKU

### oms (订单管理)
- 端口: 8004
- 功能: 订单、购物车、退货

### sms (营销管理)
- 端口: 8005
- 功能: 优惠券、秒杀、广告

### cms (内容管理)
- 端口: 8006
- 功能: 专题、优选、话题

### search (搜索服务)
- 端口: 8007
- 功能: 商品搜索

## 数据模型

详见各模块下的 `gen/model/` 目录。

### 主要数据库表

- `sys_user` - 系统用户
- `sys_role` - 角色
- `sys_menu` - 菜单
- `ums_member` - 会员
- `pms_product_spu` - 商品 SPU
- `pms_product_sku` - 商品 SKU
- `oms_order_main` - 订单
- `sms_coupon` - 优惠券
